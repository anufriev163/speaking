Преимущества

Создан для максимальной продуктивности

Никаких компромиссов: ультрабыстрый отклик, идеальная пунктуация и полный контроль над данными.

Push-to-Talk (Удержание)

Зажали клавишу — надиктовали мысль — отпустили. Текст моментально напечатался в активное окно без лишних кликов.

AI-корректор (Llama 3.3 70B)

Удаляет слова-паразиты («эээ», «нуу», «типа»), оговорки и автоматически расставляет знаки препинания под стиль общения.

Вставка в любые приложения

Интеграция через Win32 API и AppleScript. Работает в Telegram, VS Code, Notion, Microsoft Word, браузерах и терминалах.

Аппаратное шифрование ключей

Ключи доступа защищены системным DPAPI (Windows) и Keychain (macOS). Никаких открытых конфигурационных файлов.

Офлайн-режим (Faster-Whisper)

Возможность локальной транскрибации прямо на вашем процессоре или видеокарте без интернета для конфиденциальных данных.

Голосовые макросы и словарь

Сложные IT-термины, названия компаний и личные сниппеты (шаблоны писем, email, реквизиты) по одной голосовой команде.

Простая установка

Быстрый старт за 2 минуты

1 Скачайте установщик говори.exe (или .dmg для Mac) и запустите его.
2 Получите бесплатный ключ на console.groq.com (без банковской карты).
3 Вставьте ключ в окно настроек «Говори». Нажмите Ctrl + ~ в любом окне и говорите!

Предупреждение Windows SmartScreen

Так как проект новый и с открытым исходным кодом, при первом запуске Windows может показать синее окно: «Система защитила ваш компьютер».

Нажмите: «Подробнее» ➔ «Выполнить в любом случае».

Вопросы и ответы

Часто задаваемые вопросы

Действительно ли это бесплатно?
Да. Программа работает по модели BYOK (Bring Your Own Key). Облачный провайдер Groq Cloud предоставляет бесплатный тир до 14 400 запросов в день без необходимости привязывать банковскую карту. Для 99% пользователей этого хватает с огромным запасом.
Куда сохраняются мои записи и звук?
Аудиозаписи не сохраняются на диске и удаляются из оперативной памяти сразу после транскрибации. Текстовая история диктовок хранится исключительно локально на вашем ПК в файле конфигурации и никогда не отправляется третьим лицам.
Как работает режим Push-to-Talk?
В настройках переключите режим на «Удержание (PTT)». Теперь запись идет ровно столько, сколько зажата комбинация клавиш (по умолчанию Ctrl + ~). Как только вы отпустили клавишу, запись завершается и текст вставляется в активное поле ввода.
Как программа обновляется?
В приложении есть встроенный автоапдейтер. При появлении новой версии в трее или в окне настроек появится уведомление, и программа обновится в один клик.
