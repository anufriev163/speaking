Архитектура и приватность

Инженерия без компромиссов.

Создано для разработчиков, редакторов и руководителей, ценящих приватность и скорость.

100% Offline-режим и защита PII

Возможность полной автономной работы через локальный движок Whisper без выхода в интернет. Встроенный фильтр автоматически маскирует номера банковских карт и API-ключи прямо на лету.

Native Win32 C-FFI

Прямой вызов Win32 API через библиотеку koffi. Символы передаются через SendInput без затирания буфера обмена.

Голосовые макросы

Скажите «мой имейл» или «шапка письма» — приложение мгновенно развернёт длинный шаблонный текст или реквизиты.

Задержка менее 200 миллисекунд

Потоковая передача 16 кГц PCM аудио в облачный кластер Groq LPUs с моделью Whisper-large-v3-turbo. Текст появляется в окне быстрее, чем вы успеете перевести взгляд.
